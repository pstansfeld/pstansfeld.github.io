# pstansfeld.github.io

The Stansfeld Research Group website has moved to https://stansfeldlab.github.io/ (repo: [stansfeldlab/stansfeldlab.github.io](https://github.com/stansfeldlab/stansfeldlab.github.io)).

This repo only forwards old addresses: `index.html` and `404.html` send every old link (pages, games, `/group/…`) to the same path on the new site. The `.molx`/`.molj` files are kept here because Mol* links load them directly and can't follow a redirect.
