# pstansfeld.github.io

The Stansfeld Research Group website has moved to https://stansfeldlab.github.io/ (repo: [stansfeldlab/stansfeldlab.github.io](https://github.com/stansfeldlab/stansfeldlab.github.io)).

This repo only forwards old addresses: Each old page has a stub that forwards to the same page on the new site (canonical link + instant refresh, which search engines treat as a permanent redirect); `404.html` catches anything else (pages, games, `/group/…`) to the same path on the new site. The `.molx`/`.molj` files are kept here because Mol* links load them directly and can't follow a redirect.
